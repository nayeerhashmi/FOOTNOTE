# FOOTNOTE content

Editorial content will be stored in this directory as MDX files.

## Planned structure

- `issues/issue-001/` for page-level magazine content and issue metadata.
- `stories/` for individual articles that can be read outside the page-turning magazine.

## Article frontmatter

Use this shape when the publishing system is introduced:

```yaml
---
title: "Story title"
subtitle: "A short standfirst"
slug: "story-slug"
author: "Contributor name"
publishedAt: "YYYY-MM-DD"
category: "Feature"
tags: []
coverImage: "/images/story-cover.jpg"
status: "draft"
---
```

Drafts must not be treated as published stories. Verify factual claims, citations, permissions and image rights before publication.

No sample journalism or placeholder quotations are included.
